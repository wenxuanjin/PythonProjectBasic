# 基础语法练习题

本文件包含 Python 基础语法的练习题，涵盖变量、数据类型、流程控制、数据结构等内容。

## 一、变量与数据类型（10题）

### 练习 1.1：变量交换
交换两个变量 a 和 b 的值，不使用第三个变量。
```python
a = 10
b = 20
# 交换后 a = 20, b = 10
```

### 练习 1.2：类型判断
编写代码判断变量 x 的类型，并打印出来。
```python
x = "Hello"
# 输出：x 的类型是 str
```

### 练习 1.3：类型转换
将字符串 "123.45" 转换为浮点数，再转换为整数。

### 练习 1.4：字符串拼接
使用三种不同的方式拼接字符串：
```python
name = "张三"
age = 25
# 输出：我叫张三，今年25岁
```

### 练习 1.5：字符串操作
给定字符串 s = "  Hello, Python!  "，完成以下操作：
1. 去除首尾空格
2. 转换为大写
3. 统计字母 'o' 出现的次数
4. 将 "Python" 替换为 "World"

### 练习 1.6：数字格式化
将数字 3.14159265 格式化输出：
1. 保留 2 位小数
2. 保留 4 位小数
3. 以百分比形式显示（假设是 0.75）

### 练习 1.7：布尔运算
判断以下表达式的结果（True 或 False）：
```python
a = 10
b = 5
c = 10

# 1. a > b and b > 0
# 2. a == c or b > a
# 3. not (a == b)
# 4. a >= c and b <= a
```

### 练习 1.8：空值判断
编写代码判断变量是否为空（None、空字符串、空列表等）。

### 练习 1.9：进制转换
将十进制数 255 转换为：
1. 二进制
2. 八进制
3. 十六进制

### 练习 1.10：字符串切片
给定字符串 s = "Python Programming"，使用切片获取：
1. 前 6 个字符
2. 后 11 个字符
3. 反转字符串
4. 每隔一个字符取一个

- 90-100：A
- 80-89：B

- 60-69：D

编写程序判断某年是否为闰年。
闰年条件：能被4整除但不能被100整除，或者能被400整除。

### 练习 2.3：九九乘法表
使用嵌套循环打印九九乘法表。

### 练习 2.4：求和

### 练习 2.5：阶乘

### 练习 2.6：质数判断
编写程序判断一个数是否为质数。

### 练习 2.7：找出质数

### 练习 2.8：猜数字
编写一个猜数字游戏：
- 程序随机生成 1-100 的数字
- 用户输入猜测

- 直到猜对为止

### 练习 2.9：水仙花数

## 三、数据结构（10题）

### 练习 3.1：列表操作
给定列表 numbers = [3, 1, 4, 1, 5, 9, 2, 6]，完成：
1. 添加元素 7 到末尾
2. 在索引 2 处插入元素 0
3. 删除第一个值为 1 的元素
4. 对列表排序
5. 反转列表

### 练习 3.2：列表去重
去除列表中的重复元素，保持原有顺序。
```python
numbers = [1, 2, 2, 3, 3, 3, 4, 4, 4, 4]
# 结果：[1, 2, 3, 4]
```

### 练习 3.3：列表推导式
使用列表推导式完成：
1. 生成 1-10 的平方列表
2. 筛选出列表中的偶数
3. 将字符串列表转换为大写

### 练习 3.4：字典操作
创建一个学生信息字典，包含姓名、年龄、成绩，完成：
1. 添加新的键值对
2. 修改成绩
3. 删除年龄
4. 遍历所有键值对

### 练习 3.5：字典统计
统计字符串中每个字符出现的次数。
```python
text = "hello world"
# 结果：{'h': 1, 'e': 1, 'l': 3, 'o': 2, ' ': 1, 'w': 1, 'r': 1, 'd': 1}
```

### 练习 3.6：集合操作
给定两个集合：
```python
set_a = {1, 2, 3, 4, 5}
set_b = {4, 5, 6, 7, 8}
```
计算：并集、交集、差集、对称差集

### 练习 3.7：元组解包
使用元组解包交换多个变量的值。

### 练习 3.8：嵌套数据结构
给定嵌套列表，计算所有数字的和：
```python
nested = [[1, 2, 3], [4, 5], [6, 7, 8, 9]]
```

### 练习 3.9：排序
对学生列表按成绩降序排序：
```python
students = [
    {"name": "张三", "score": 85},
    {"name": "李四", "score": 92},
    {"name": "王五", "score": 78},
]
```

### 练习 3.10：合并字典
合并两个字典，如果有相同的键，值相加：
```python
dict1 = {"a": 1, "b": 2, "c": 3}
dict2 = {"b": 3, "c": 4, "d": 5}
# 结果：{"a": 1, "b": 5, "c": 7, "d": 5}
```
